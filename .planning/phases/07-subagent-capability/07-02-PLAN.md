  <behavior>
    - createSpawnHandler(profiles, subagentBatch, startLoop, maxSubagents):
        returns LocalToolHandler for spawn_subagent tool
        validates profile exists in profiles array — returns error string if not found
        checks subagentBatch.size < maxSubagents — returns error string if at cap
        calls startLoop(systemPrompt, task, []) with fresh history — stores Promise in batch
        returns confirmation string: "Subagent '{subagent_id}' started with profile '{profile}'."
    - createCollectHandler(subagentBatch):
        returns LocalToolHandler for collect_results tool
        returns "No active subagents to collect." when batch empty
        wraps Promise.allSettled in Promise.race against timeout (default 120_000ms)
        clears subagentBatch after collecting
        returns JSON.stringify of settled results on success
        returns "[error]: Batch timed out after Nms" on timeout
    - spawn_subagent JSON schema includes: profile (string, required), task (string, required), subagent_id (string, required)
    - collect_results JSON schema includes: timeout_ms (number, optional)
    - Exported factory functions: createSpawnHandler, createCollectHandler
    - Exported helper: createSpawnToolDef() and createCollectToolDef() — returns LocalToolDef for each

    NOTE: createSpawnHandler receives startLoop as a parameter (injected dependency) — do NOT import startAgentLoop directly here. This keeps local-tools.ts testable without agent.ts.
