    - insert({ content, verbose: true }) → returns {id, content, path, metadata, created_at, chunk_count}

Zod inputSchema:
```typescript
{
  content: z.string().min(1, "Content must not be empty").max(50_000),
  path: z.array(z.string()).optional().describe("Path hierarchy e.g. ['tasks', 'home']"),
  metadata: z.record(z.unknown()).optional(),
  chunk_size: z.number().int().positive().optional(),
  chunk_overlap: z.number().int().min(0).optional(),
  verbose: z.boolean().optional(),
}
```

**Handler logic (order matters — per RESEARCH.md anti-patterns):**
1. Validate content (Zod handles min/max; also reject whitespace-only: `content.trim().length === 0`)
2. Read chunk config: `chunkSize = input.chunk_size ?? parseInt(process.env.CHUNK_SIZE ?? "2000")`, `chunkOverlap = input.chunk_overlap ?? parseInt(process.env.CHUNK_OVERLAP ?? "200")`
3. Get provider: `const provider = createEmbeddingProvider()`
4. Chunk the text: `const chunks = chunkText(content, chunkSize, chunkOverlap)`
5. Embed all chunks: `const vectors = await Promise.all(chunks.map(c => provider.embed(c)))` — if ANY fails, return toolError("EMBEDDING_FAILED", ...)
6. Write atomically in `withAgent(agentId, async (client) => { ... })`:
   - INSERT INTO entries(...) RETURNING id
   - INSERT INTO chunks(entry_id, chunk_index, embedding) VALUES ... (all chunks in one statement or loop within same transaction)
7. Build response: default `{id, content, path: input.path ?? []}`. If `verbose: true`, add `{metadata, created_at, chunk_count: chunks.length}`
8. Return `{ content: [{ type: "text", text: JSON.stringify(result) }] }`

Note: agentId comes from function parameter (passed from authMiddleware via server.registerTool extra context) — NOT from tool input. The tool inputSchema must NOT include an agentId field.

Log structured JSON on success: `{timestamp, level: "info", operation: "insert", agent_id, entry_id, chunks, duration_ms}`

**Handler logic:**

- **Semantic search mode** (query present): embed query → call `SELECT * FROM match_entries($1, $2, $3, $4, $5)` with `(queryVector, threshold, count, filter ?? null, path ?? null)`.
- Build response array. Default fields per row: `{id, content, path}`. If `verbose: true`, add `{similarity, metadata, created_at, matched_chunk}`.
- Return `{ content: [{ type: "text", text: JSON.stringify(results) }] }`

Do NOT include raw embedding vectors in any response.
