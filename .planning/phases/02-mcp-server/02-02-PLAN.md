Export: `pool`, `withAgent`

**mcp/src/chunker.ts:**

`chunkText(text: string, chunkSize: number, chunkOverlap: number): string[]`

Validate at call time: if `chunkOverlap >= chunkSize` throw new Error(`CHUNK_OVERLAP (${chunkOverlap}) must be less than CHUNK_SIZE (${chunkSize})`).

Implementation uses character-based sliding window (per CONTEXT.md — "character-based vs token-based is Claude's discretion"):
```typescript
if (text.length <= chunkSize) return [text];
const chunks: string[] = [];
let start = 0;
while (start < text.length) {
  const end = Math.min(start + chunkSize, text.length);
  chunks.push(text.slice(start, end));
  if (end === text.length) break;
  start += chunkSize - chunkOverlap;
}
return chunks;
```

Export: `chunkText`

**Startup validation** (in db.ts module body, not in withAgent): read `CHUNK_SIZE` and `CHUNK_OVERLAP` env vars and call a validateChunkConfig() helper that throws if overlap >= size. This catches misconfiguration on container start, not on first insert.
