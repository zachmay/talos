<!-- EmbeddingProvider contract for all downstream tool handlers -->
```typescript
export interface EmbeddingProvider {
  embed(text: string): Promise<number[]>;
  readonly dimensions: number;
}

// Factory — the ONLY way tool handlers should get a provider
export function createEmbeddingProvider(): EmbeddingProvider;
```

EMBEDDING_MODEL    = model string (provider-specific default if absent)
EMBEDDING_API_KEY  = API key (required for cloud providers)
VECTOR_DIMENSIONS  = "1536" (default; must match DB column dimensions from Phase 1)
OLLAMA_BASE_URL    = "http://localhost:11434" (default for Ollama)

Each provider reads its config from env vars in the constructor (not at module load — only when instantiated). All providers throw errors prefixed with "EMBEDDING_FAILED: " on non-OK HTTP responses.

**mcp/src/providers/openrouter.ts** — `OpenRouterProvider implements EmbeddingProvider`:
- Constructor reads: `EMBEDDING_MODEL` (default: `"openai/text-embedding-3-small"`), `EMBEDDING_API_KEY`, `VECTOR_DIMENSIONS` (default: `1536`)
- `embed(text)`: POST to `https://openrouter.ai/api/v1/embeddings` with `{model, input: text}` and `Authorization: Bearer {apiKey}` header
- Response shape: `data.data[0].embedding` (array of numbers)
- On non-OK: throw `new Error(\`EMBEDDING_FAILED: \${res.status} \${await res.text()}\`)`

**mcp/src/providers/openai.ts** — `OpenAIProvider implements EmbeddingProvider`:
- Constructor reads: `EMBEDDING_MODEL` (default: `"text-embedding-3-small"`), `EMBEDDING_API_KEY`, `VECTOR_DIMENSIONS` (default: `1536`)
- `embed(text)`: POST to `https://api.openai.com/v1/embeddings` with `{model, input: text}` and `Authorization: Bearer {apiKey}` header
- Response shape: `data.data[0].embedding`

**mcp/src/providers/ollama.ts** — `OllamaProvider implements EmbeddingProvider`:
- Constructor reads: `EMBEDDING_MODEL` (default: `"nomic-embed-text"`), `OLLAMA_BASE_URL` (default: `"http://localhost:11434"`), `VECTOR_DIMENSIONS` (default: `768`)
- `embed(text)`: POST to `${baseUrl}/api/embeddings` with `{model, prompt: text}` (Ollama uses `prompt`, not `input`)
- Response shape: `data.embedding`

**mcp/src/providers/anthropic.ts** — `AnthropicProvider implements EmbeddingProvider`:

- Constructor: reads same env vars; sets `dimensions = parseInt(process.env.VECTOR_DIMENSIONS ?? "1536", 10)`
- `embed(text)`: throws `new Error("EMBEDDING_FAILED: Anthropic embeddings API not verified — use EMBEDDING_PROVIDER=openrouter")`
