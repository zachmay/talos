Section 1 — Threat Model and Attack Surfaces:
For each attack surface, provide: description, mitigations in place (factual), residual risk. Surfaces to cover:

1. Agent Escape — agent attempts to access host filesystem or spawn privileged processes. Mitigations: read_only rootfs, cap_drop ALL, no-new-privileges, seccomp profile (agent/seccomp-standard.json, Docker default v28.0.1 base). Residual: seccomp profile strength not independently verified; gVisor (agent-strict profile) requires manual host install.

2. MCP Injection — malicious agent sends crafted tool arguments to extract data belonging to other agents. Mitigations: RLS enforced with FORCE ROW LEVEL SECURITY on entries and audit_log; mcp_service role has only SELECT/INSERT/UPDATE/DELETE on its own rows. Residual: RLS policies are only as strong as their WHERE clause implementation.

3. Credential Leakage — API keys or database passwords appear in image layers, logs, or environment dumps. Mitigations: credentials injected as Docker secrets (files at /run/secrets/), not env vars; no secrets in docker-compose.yml defaults. Residual: secrets visible to processes inside the container via /run/secrets/ file reads.

4. Embedding Data Exfiltration — text content is sent to cloud embedding APIs without operator knowledge. Mitigations: all embedding is owned by MCP server (agents never call embedding providers directly); provider is documented and configurable; Ollama provides fully local option. Residual: when using cloud embedding, text chunks are sent to OpenRouter or OpenAI; no content filtering or redaction is applied.

5. Cross-Agent Data Access — one agent attempts to read rows belonging to another agent identity. Mitigations: each agent uses a separate bearer token; MCP server extracts agent identity from token and passes to DB; RLS policy restricts rows by agent_id. Residual: a compromised MCP server could bypass RLS.

6. DB Network Exposure — Postgres port is reachable from outside the Docker network. Mitigations: DB on backend network (not frontend); agent cannot reach DB. Residual: ports mapping "${DB_PORT:-5432}:5432" publishes Postgres to the host — Docker binds to 0.0.0.0 by default, exposing the port to any interface unless host firewall prevents it.

7. Dependency Chain Attacks — malicious npm packages in agent or MCP install. Mitigations: no automatic npm install at runtime; packages are installed at image build time from package-lock.json. Residual: npm supply chain attacks in dependencies are not audited at build time.
